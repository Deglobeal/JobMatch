# JobMatch

JobMatch helps job seekers discover jobs that match their CV or target role, analyze job requirements, tailor their CV, and generate a customized cover letter.

## Applications

- Web — Next.js
- API — FastAPI
- Android — React Native / Expo

## MVP Flow

CV or target job
→ Search
→ Matching jobs
→ View original job
→ Match analysis
→ Tailor CV
→ Generate cover letter
→ Track application
